# pymongo-api

## Как запустить

### Запускаем все контейнеры

Находясь в папке проекта sharding-repl-cache

```shell
docker compose up -d
```

При этом важно что не все сервисы запустятся корректно (так как они требуют корректной инициализации кластера)
- mongo_router1 - запустится, но healthcheck не пройедт
- pymongo_api - не запустаться вообще, так как зависит от mongo_router1
Перечисленные проблемы уйдут после следующей команды

### Инициализируем кластер

Находясь в папке проекта sharding-repl-cache

```shell
./scripts/01-init.sh
```

### Заполняем тестовыми данными

Находясь в папке проекта sharding-repl-cache

```shell
./scripts/02-seed.sh
```

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080

## Доступные эндпоинты

Список доступных эндпоинтов, swagger http://<ip виртуальной машины>:8080/docs
